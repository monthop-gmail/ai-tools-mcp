# ADR-0004: `unclassified` ไม่ใช่ `privileged` — fail-closed อยู่ที่พฤติกรรม ไม่ใช่ที่การเดาค่าลงบันทึก

**Status:** Proposed
**Date:** 2026-10-12
**Depends on:** ADR-0003
**Blocking:** ADR-0007
**Supersedes:** —
**Related ws-001:** `dis-514ae7a7` seq 7 ข้อ ข-1 · seq 14 · seq 59

## Context

ทะเบียนที่จำแนก operation ของ tool ย่อมล้าสมัยกว่าของจริงเสมอ — ปลายทางเพิ่ม tool ใหม่โดยทะเบียนยังไม่รู้จัก

✅ พฤติกรรมที่ถูกคือ **ปฏิเสธ** เพื่อให้ระบบแคบลงเมื่อล้าสมัย ไม่ใช่กว้างขึ้น · ข้อนี้ไม่มีใครเถียง
และเกิดจริงครั้งแรกเมื่อ 21 ก.ย. (`dis-514ae7a7` seq 59) ตอนที่ปลายทางเพิ่ม tool ใหม่แล้วถูกปฏิเสธที่ชั้น gateway

🟡 แต่ร่างแรกของ runtime บันทึก tool ที่ทะเบียนไม่รู้จักลง audit ว่า **`operation: privileged`**
ซึ่งเป็น **คำกล่าวอ้างเกี่ยวกับ tool ที่ไม่มีใครเคยจำแนก**

ผลสองข้อ:

1. ถ้ามีคนนับว่า "เดือนนี้ปฏิเสธคำขอ privileged กี่ครั้ง" ตัวเลขจะผิด เพราะปนกับ tool ที่แค่ยังไม่ได้ลงทะเบียน
2. แยกไม่ออกระหว่าง *นโยบายทำงานถูก* กับ *ทะเบียนล้าสมัย* ซึ่งเป็นปัญหาคนละอย่างและแก้คนละทาง

## Options

### A. `unclassified` เป็นค่าในตัวเอง · ปฏิเสธเหมือนเดิม (แนะนำ)

* ✅ พฤติกรรมไม่เปลี่ยนเลย — ยังปฏิเสธ ยัง fail-closed
* ✅ บันทึกพูดความจริงว่า *เราไม่รู้ว่านี่คืออะไร* ต่างจาก *เรารู้ว่าอันนี้อันตราย*
* ✅ นับแยกได้ จึงรู้ว่าต้องไปอัปเดตทะเบียน ไม่ใช่ไปทบทวนนโยบาย
* ❌ เพิ่มค่าใน enum หนึ่งค่า ผู้อ่านที่ไล่ค่าแบบตายตัวต้องรู้

### B. ยุบเป็น `privileged` ตามร่างแรก

* ✅ ไม่ต้องเพิ่มค่า
* ❌ บันทึกอ้างสิ่งที่ไม่มีใครตรวจ · และซ่อนสาเหตุที่แท้จริงของการปฏิเสธ

## Decision

**A** — `unclassified` เป็นค่าของ operation ในตัวเอง · ปฏิเสธเหมือนเดิมทุกประการ · บันทึกไม่เดา

> **fail-closed อยู่ที่พฤติกรรม ไม่ใช่ที่การเดาค่าที่แรงที่สุดลงในบันทึก**

และรหัสเหตุผลของการปฏิเสธต้องแยก *ทะเบียนไม่รู้จัก* ออกจาก *operation ไม่ได้รับอนุญาต*

**Reason:** หลักเดียวกับ ADR-0003 ข้อ 4 — เมื่อไม่รู้ ให้ลงค่าที่อ่านออกว่าไม่รู้ · การเดาค่าที่แรงที่สุด
ยังเป็นการเดา และมันทำให้ตัวเลขที่คนเอาไปใช้ตัดสินใจผิด

**Authority:** — `Proposed` · พฤติกรรมนี้ถูก implement ในรีโป runtime 🔒 แล้วตั้งแต่ 17 ก.ย. แต่ยังไม่มีใบรองรับ

## Consequences

* ชุด conformance ต้องมีเวกเตอร์ tool ที่ไม่มีในทะเบียน แล้วยืนยันทั้ง **การปฏิเสธ** และ **ค่าที่บันทึก**
* ผู้ที่นับสถิติ privileged ได้ตัวเลขที่ใช้ได้จริง
* ทีมที่ดูแลทะเบียนมีสัญญาณว่าต้องอัปเดต แยกจากสัญญาณว่านโยบายตึงเกินไป
